# OrchardVM
OrchardVM is a Emulator app that is directly on Android Phones that allow to emulate iOS and more

# Features
- iOS (iPod Touch 2.0) / (iPhone 11, iOS 14)
- Windows Phone (In creation)
- Windows (KVM only) (In creation)
